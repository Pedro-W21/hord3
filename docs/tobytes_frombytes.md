# Serialization and Deserialization in Hord3

Serialization and deserialization are implemented and derived using my crate also found in this repo : `to_from_bytes`, this has 2 important traits :
- `ToBytes` : allows for turning an implementing type into raw bytes
- `FromBytes` : allows for constructing an implementing type from raw bytes generated by `ToBytes`

together (with their associated derive macros) these provide most/all of Hord3's serialization and deserialization.

## Why not use `serde` ?

Like much of this project, I wanted to learn how to do it myself. Do I think mine's better ? No. But it does what I need it to now.
